# Daily — Design / CI

กฎการออกแบบของ Daily รวบรวมจากที่เจ้าของบอกไว้ตั้งแต่เริ่มโปรเจกต์ ใช้กับทุกงาน ได้แก่ แอป, หน้าเว็บ/landing, อีเมล, splash, วิดีโอ และ social
ถ้าจะทำอะไรที่ขัดกับไฟล์นี้ ต้องถามเจ้าของก่อน

## แนวทางหลัก
- **"Instagram + Apple minimal but art"**: เรียบแบบ Apple มีความเป็นงานศิลป์/โปสเตอร์ และใช้ง่ายแบบแอปโซเชียล
- **"ไม่ไล่สี ไม่มีเส้นกรอบ ทำ art art"** (กฎที่สำคัญที่สุด):
  - สีทึบ (flat) เท่านั้น ห้ามไล่สี (gradient)
  - ห้ามเส้นกรอบ (border/outline/stroke) และห้ามเส้นคั่น
  - แยกส่วนต่าง ๆ ด้วย **บล็อกสี** และ **ระยะห่าง** แทน
  - ห้ามตัวหนังสือแบบเส้นขอบ (outline text)
  - ห้ามเงานุ่ม/เงาฟุ้งบน UI
  - เงาที่ใช้ได้มีแบบเดียว คือเงาทึบเยื้อง (hard offset ไม่เบลอ) เช่น ปุ่มที่มีเงามะนาวทึบ ซึ่งนับเป็นบล็อกสี
  - ข้อยกเว้นเดียว: ภาพวาดมะนาว (`icons/lemon.svg`) มีแสงเงาในตัวภาพได้
- **ไม่ลอกแบบใคร**: ภาพ reference ใช้ดูแค่ concept เท่านั้น (เคยบอกกับ Duolingo และ Paypers) ต้องออกมาเป็นดีไซน์ของ Daily เอง
- **Global**: ทุกงานต้องรองรับหลายภาษา (18 ภาษา) และหลายสกุลเงิน ห้ามผูกกับไทยอย่างเดียว
  - ตัวอย่างจำนวนเงินในหน้าเว็บและภาพประกอบต้องเป็นสกุลเงินของผู้ชม (ตามประเทศ) และใช้รูปแบบตัวเลขตามภาษา ห้ามเขียน ฿ ตายตัว
  - ข้อความในภาษาอื่นห้ามพูดถึง "บาท" (เช่น "every baht") ให้ใช้คำกลางๆ อย่าง "every coin"

## ตัวอักษร
- **Google Fonts เท่านั้น** ห้ามโหลดฟอนต์จากที่อื่น
- **ในแอป:** ใช้ Google Sans อย่างเดียว ("ใช้ google san")
- **ใน marketing:**
  - หัวข้อภาษาไทยใช้ Anuphan (Google Sans ไม่มีภาษาไทย)
  - ตัวโปสเตอร์ใหญ่ (DAILY และตัวเลข 01 02 03) ใช้ Big Shoulders Display 900
- **Wordmark "Daily":** Google Sans 700, letter-spacing −0.03em ตามด้วยรูปมะนาว
- ฟอนต์ห้ามกระพริบหรือหาย: splash ใช้ wordmark เป็น SVG path

## ไอคอน
- **Google Material Symbols Rounded** เท่านั้น ("icon use google icon")
  - ในแอปใช้ subset ชื่อ "Daily Symbols"
  - ชื่อไอคอนหมวดต้องตรงกับ `^[a-z0-9_]{1,40}$` และต้องมีอยู่ใน subset

## โลโก้ / มาสคอต
- **มะนาวลูกเต็ม** ไม่ใช่ลูกผ่าครึ่ง ("เอาที่หั่นออก")
  - เป็นภาพวาดละเอียดแบบงานศิลป์ ทำเป็น vector อยู่ที่ `icons/lemon.svg`
- ใช้มะนาวเป็นลูกเล่นได้ทุกที่ ("ตรงไหนที่เอา logo ไปแทรกได้ทำเลย เป็นลูกเล่น") เช่น
  - มุมการ์ดยอด, splash
  - มะนาวหล่นใน landing
- ชื่อแอปคือ **Daily** เท่านั้น ห้ามใส่ ฿ ต่อท้าย ("฿ เอาออกได้มั้ย ไม่ชอบ")

## รูปทรง (shape language)
- **มุมใบไม้:** โค้งเฉพาะมุมทแยง `border-radius: 0 R 0 R` ใช้กับการ์ด ปุ่มหลัก ป้าย และแถบ
- **รูปทรงทึบวนกัน** สำหรับไอคอนหมวด: วงกลมน้ำเงิน, วงกลมมะนาว, สี่เหลี่ยมดำ, หยดน้ำ (`50% 50% 0 50%`)
- รูปทรงเรขาคณิตทึบ คือ "art" ของแอป ใช้แทนภาพประกอบ

## ขนาดและการจัดวาง
- เจ้าของสั่งให้ลดขนาดลง 15% สองรอบ ("ทุกอย่างใหญ่ไป") ตอนนี้ `html { zoom: .85 }` ห้ามขยายกลับ
- **ตัวเลขเงิน:**
  - ชิดขวา แต่ห้ามติดหน่วยหรือติดขอบ
  - ห้ามตัวเลขหรือเลข 0 โดนตัด
  - หน่วยสกุลเงินไว้ด้านขวาของจำนวน
- **ฟีเจอร์หลักอยู่แถบล่าง:** รายการ, สรุป, + , สแกนบิล, AI
- **หน้าหลักเป็นหน้า ไม่ใช่ป๊อปอัป**
- ต้องมีปุ่มย้อนกลับ/ปิดเสมอ
- **Desktop ≥1024px:** sidebar + list + summary (รายละเอียดอยู่ใน CLAUDE.md)
  - ส่วนกลางห้ามยาวเกินไปบนจอกว้าง
  - ปรับด้วยตัวแปร ไม่ต้องเปลี่ยนโครง

## ลำดับขั้นตอน ห้ามใช้ตัวเลข
เจ้าของต้องการให้ผู้ใช้รู้ลำดับได้เอง โดยไม่ต้องใส่ 1 2 3 จึงใช้หลักจิตวิทยาการมองเห็นแทน:
- **ทิศการอ่าน:** วางเรียงซ้าย→ขวา หรือบน→ล่าง ซึ่งเป็นทิศที่ทุกภาษาที่รองรับอ่านอยู่แล้ว
- **เส้นทางต่อเนื่อง (Gestalt continuity):** มีแถบทึบสีมะนาวแถบเดียวร้อยทุกขั้นเข้าด้วยกัน
- **Goal gradient:** แถบเริ่มบางแล้วหนาขึ้นจนถึงเป้าหมาย และแต่ละขั้นมีขนาดใหญ่ขึ้นเรื่อยๆ
- **ปลายทางชัด:** มีมะนาว (มาสคอต) รออยู่ที่ปลายแถบ
- **ของชิ้นเดียวเปลี่ยนสถานะ:** บิล → รายการ → ยอดคงเหลือ ผู้ใช้เห็นเรื่องเดียวกันเดินหน้า เลยรู้ลำดับเอง
- **หัวข้อเป็นคำกริยาตามลำดับเหตุการณ์:** ถ่าย → แยก → เห็น
- **ภาพค่อยๆ ขึ้นตามลำดับ (stagger)** ตอนเลื่อนมาถึง
- **โค้ด:** ใช้ `<ol>` เพื่อให้ screen reader ยังอ่านลำดับได้ ทั้งที่บนจอไม่มีเลข

## การเคลื่อนไหว
- สไตล์ Apple: นุ่ม และมีจังหวะเดียวแล้วหยุด ("animation style apple product")
- ปุ่มสลับรายรับ/รายจ่ายเป็น segmented control ที่เลื่อนแบบ smooth
- พื้นหลังของแผ่นที่เลื่อนขึ้น (sheet) เบลอได้ ("เห็นข้างหลังแล้วแปลก ลองเบลอ")
  - เบลอเป็นการกันสายตา ไม่ใช่การตกแต่ง
- เคารพ `prefers-reduced-motion` เสมอ
- Splash:
  - พื้นกรมท่า มี wordmark และมะนาว
  - แสดงอย่างน้อย 0.9 วินาที
  - ห้ามกระพริบ
  - ไม่ใช้ภาพ launch ของ iPhone

## UX ที่เจ้าของย้ำ
- เลือกหลายอันก่อน แล้วค่อยกดยืนยันทีเดียว
- ปัดซ้ายเพื่อลบ ต้องมีขั้นยืนยัน
- ข้อความ error เป็นภาษาคน
- ห้ามบอกชื่อผู้ให้บริการอัตราแลกเปลี่ยนใน UI (บอกได้แค่ว่าเป็นอัตราอ้างอิง)
- ถ้ายังไม่ได้เชื่อม AI ให้ซ่อนปุ่มที่เกี่ยวกับ AI
- ภาษาและสกุลเงินเริ่มต้นตั้งตามประเทศของผู้ใช้

## Marketing / landing
- เจ้าของชอบ **แบบโปสเตอร์ (v1)** มากที่สุด:
  - พื้นกระดาษมีเกรน
  - ตัว DAI/LY สูงแคบ
  - มีมะนาวหล่น
  - ปุ่มมีเงามะนาวทึบ
- ผสม Apple ได้แค่นิดเดียว ("apple ไปหน่อย") คือ:
  - แอปจริงอยู่ในกรอบมือถือ
  - แถบบนโปร่ง
  - ลิงก์ "›"
- ไฟล์ที่ใช้อยู่ตอนนี้: `marketing/landing-mix.html` (v3) ส่วน v1 และ v2 เก็บไว้ดูเป็น reference
- ส่วนอธิบาย (explainer):
  - ตัวเลขโปสเตอร์ทึบ, highlight สีมะนาวใต้คำ, การ์ดมุมใบไม้ที่เป็นบล็อกสี
  - ไม่มีเส้นกรอบ ไม่มีเส้นคั่น
- อีเมล (auth) ใช้ดีไซน์เดียวกัน: กรมท่า/มะนาว, มุมใบไม้, 18 ภาษา
- วิดีโอ: เอาแค่ concept จาก reference, หน้าจอต้องเป็น UI จริงของ Daily, ฟอนต์ Google Sans
