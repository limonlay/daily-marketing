# Daily — Design / CI

กฎการออกแบบของ Daily รวบรวมจากที่เจ้าของบอกไว้ตั้งแต่เริ่มโปรเจกต์ ใช้กับทุกงาน ได้แก่ แอป, หน้าเว็บ/landing, อีเมล, splash, วิดีโอ และ social
ถ้าจะทำอะไรที่ขัดกับไฟล์นี้ ต้องถามเจ้าของก่อน

## แนวทางหลัก
- **"Instagram + Apple minimal but art"**: เรียบแบบ Apple มีความเป็นงานศิลป์/โปสเตอร์ และใช้ง่ายแบบแอปโซเชียล
- **"ไม่ไล่สี ไม่มีเส้นกรอบ ทำ art art"** (กฎที่สำคัญที่สุด):
  - สีทึบ (flat) เท่านั้น ห้ามไล่สี (gradient)
  - ห้ามเส้นกรอบ (border/outline/stroke) และห้ามเส้นคั่น
  - แยกส่วนต่าง ๆ ด้วย **บล็อกสี** และ **ระยะห่าง** แทน
  - ห้ามตัวหนังสือแบบเส้นขอบ (outline text)
  - ห้ามเงานุ่ม/เงาฟุ้งบน UI
  - เงาที่ใช้ได้มีแบบเดียว คือเงาทึบเยื้อง (hard offset ไม่เบลอ) เช่น ปุ่มที่มีเงามะนาวทึบ ซึ่งนับเป็นบล็อกสี
  - ข้อยกเว้นเดียว: ภาพวาดมะนาว (`icons/lemon.svg`) มีแสงเงาในตัวภาพได้
  - ข้อยกเว้นเพื่อการใช้งาน: กรอบโฟกัสสีมะนาวตอนใช้คีย์บอร์ด (`:focus-visible`) ต้องมีไว้เพื่อการเข้าถึง และลูกศรสามเหลี่ยมที่ทำด้วยเทคนิค border ซึ่งบนจอเป็นรูปทรงทึบ
  - ขอบที่ตัดเนื้อหาหรือปุ่มที่ลอยอยู่ ใช้บล็อกสีพื้นทึบบังแทนเงาจาง
- **ไม่ลอกแบบใคร**: ภาพ reference ใช้ดูแค่ concept เท่านั้น (เคยบอกกับ Duolingo และ Paypers) ต้องออกมาเป็นดีไซน์ของ Daily เอง
- **Global**: ทุกงานต้องรองรับหลายภาษา (18 ภาษา) และหลายสกุลเงิน ห้ามผูกกับไทยอย่างเดียว
  - ตัวอย่างจำนวนเงินในหน้าเว็บและภาพประกอบต้องเป็นสกุลเงินของผู้ชม (ตามประเทศ) และใช้รูปแบบตัวเลขตามภาษา ห้ามเขียน ฿ ตายตัว
  - ข้อความในภาษาอื่นห้ามพูดถึง "บาท" (เช่น "every baht") ให้ใช้คำกลางๆ อย่าง "every coin"

## ตัวอักษร
- **Google Fonts เท่านั้น** ห้ามโหลดฟอนต์จากที่อื่น
- **ในแอป:** ใช้ Google Sans อย่างเดียว ("ใช้ google san")
- **ใน marketing:**
  - หัวข้อภาษาไทยใช้ Anuphan (Google Sans ไม่มีภาษาไทย)
  - ตัวโปสเตอร์ใหญ่ (DAILY และตัวเลข 01 02 03) ใช้ Big Shoulders Display 900
- **Wordmark "Daily":** Google Sans 700, letter-spacing −0.03em ตามด้วยรูปมะนาว
- ฟอนต์ห้ามกระพริบหรือหาย: splash ใช้ wordmark เป็น SVG path

## ไอคอน
- **Google Material Symbols Rounded** เท่านั้น ("icon use google icon")
  - ในแอปใช้ subset ชื่อ "Daily Symbols"
  - ชื่อไอคอนหมวดต้องตรงกับ `^[a-z0-9_]{1,40}$` และต้องมีอยู่ใน subset

## โลโก้ / มาสคอต
- **มะนาวลูกเต็ม** ไม่ใช่ลูกผ่าครึ่ง ("เอาที่หั่นออก")
  - เป็นภาพวาดละเอียดแบบงานศิลป์ ทำเป็น vector อยู่ที่ `icons/lemon.svg`
- ใช้มะนาวเป็นลูกเล่นได้ทุกที่ ("ตรงไหนที่เอา logo ไปแทรกได้ทำเลย เป็นลูกเล่น") เช่น
  - มุมการ์ดยอด, splash
  - มะนาวหล่นใน landing
- ชื่อแอปคือ **Daily** เท่านั้น ห้ามใส่ ฿ ต่อท้าย ("฿ เอาออกได้มั้ย ไม่ชอบ")

## รูปทรง (shape language)
- **มุมใบไม้:** โค้งเฉพาะมุมทแยง `border-radius: 0 R 0 R` ใช้กับการ์ด ปุ่มหลัก ป้าย และแถบ
- **รูปทรงทึบวนกัน** สำหรับไอคอนหมวด: วงกลมน้ำเงิน, วงกลมมะนาว, สี่เหลี่ยมดำ, หยดน้ำ (`50% 50% 0 50%`)
- รูปทรงเรขาคณิตทึบ คือ "art" ของแอป ใช้แทนภาพประกอบ

## ขนาดและการจัดวาง
- เจ้าของสั่งให้ลดขนาดลง 15% สองรอบ ("ทุกอย่างใหญ่ไป") ตอนนี้ `html { zoom: .85 }` ห้ามขยายกลับ
- **ตัวเลขเงิน:**
  - ชิดขวา แต่ห้ามติดหน่วยหรือติดขอบ
  - ห้ามตัวเลขหรือเลข 0 โดนตัด
  - หน่วยสกุลเงินไว้ด้านขวาของจำนวน
- **ฟีเจอร์หลักอยู่แถบล่าง:** รายการ, สรุป, + , สแกนบิล, AI
- **หน้าหลักเป็นหน้า ไม่ใช่ป๊อปอัป**
- ต้องมีปุ่มย้อนกลับ/ปิดเสมอ
- **Desktop ≥1024px:** sidebar + list + summary (รายละเอียดอยู่ใน CLAUDE.md)
  - ส่วนกลางห้ามยาวเกินไปบนจอกว้าง
  - ปรับด้วยตัวแปร ไม่ต้องเปลี่ยนโครง

## ลำดับขั้นตอน ห้ามใช้ตัวเลข
เจ้าของต้องการให้ผู้ใช้รู้ลำดับได้เอง โดยไม่ต้องใส่ 1 2 3 จึงใช้หลักจิตวิทยาการมองเห็นแทน:
- **ทิศการอ่าน:** วางเรียงซ้าย→ขวา หรือบน→ล่าง ซึ่งเป็นทิศที่ทุกภาษาที่รองรับอ่านอยู่แล้ว
- **เส้นทางต่อเนื่อง (Gestalt continuity):** มีแถบทึบสีมะนาวแถบเดียวร้อยทุกขั้นเข้าด้วยกัน
- **Goal gradient:** แถบเริ่มบางแล้วหนาขึ้นจนถึงเป้าหมาย และแต่ละขั้นมีขนาดใหญ่ขึ้นเรื่อยๆ
- **ปลายทางชัด:** มีมะนาว (มาสคอต) รออยู่ที่ปลายแถบ
- **ของชิ้นเดียวเปลี่ยนสถานะ:** บิล → รายการ → ยอดคงเหลือ ผู้ใช้เห็นเรื่องเดียวกันเดินหน้า เลยรู้ลำดับเอง
- **หัวข้อเป็นคำกริยาตามลำดับเหตุการณ์:** ถ่าย → แยก → เห็น
- **ภาพค่อยๆ ขึ้นตามลำดับ (stagger)** ตอนเลื่อนมาถึง
- **โค้ด:** ใช้ `<ol>` เพื่อให้ screen reader ยังอ่านลำดับได้ ทั้งที่บนจอไม่มีเลข

## การเคลื่อนไหว
- สไตล์ Apple: นุ่ม และมีจังหวะเดียวแล้วหยุด ("animation style apple product")
- ปุ่มสลับรายรับ/รายจ่ายเป็น segmented control ที่เลื่อนแบบ smooth
- พื้นหลังของแผ่นที่เลื่อนขึ้น (sheet) เบลอได้ ("เห็นข้างหลังแล้วแปลก ลองเบลอ")
  - เบลอเป็นการกันสายตา ไม่ใช่การตกแต่ง
- เคารพ `prefers-reduced-motion` เสมอ — แทนการเลื่อน/เด้งด้วย fade สั้น ไม่ใช่ปิดทุกอย่าง
- **ค่ามาตรฐาน (ใช้ร่วมกันทุกหน้า, ระบบ 18a):**
  - เวลา: แตะ 120ms · เปลี่ยนเล็ก 200ms · หน้า 320ms · แผ่นเลื่อนขึ้น 380ms · ไม่เกิน 450ms ยกเว้นฉากฉลอง
  - easing: ออกนุ่ม `cubic-bezier(.2,.8,.2,1)` · เด้งนิดเดียวแล้วหยุด (overshoot ~6%) สำหรับของที่ "เกิดขึ้น" เช่น คำใบ้ ป้าย การ์ดฉลอง
  - ออกเร็วกว่าเข้า ~20% · ขยับเฉพาะ `transform` / `opacity` (ไม่ขยับ layout)
  - **ในโค้ดใช้ตัวแปร CSS เท่านั้น ห้ามเขียนตัวเลขเอง** (กำหนดใน `index.html` บล็อก "Motion tokens"):
    `--t-tap` 120ms · `--t-quick` 200ms · `--t-page` 320ms · `--t-sheet` 380ms · `--t-max` 450ms;
    ตอนออก `--t-quick-out` 160ms · `--t-page-out` 260ms · `--t-sheet-out` 300ms;
    `--ease-out` (ทุกอย่างที่เคลื่อน) · `--ease-spring` (ของที่ "เกิดขึ้น") — `--spring` เป็นชื่อเก่า = `--ease-out`
  - เทคนิคเข้า/ออกคนละเวลา: rule ปกติใช้ค่า `-out` แล้ว rule ตอนเปิด (`.open` / `.show`) เปลี่ยน `transition-duration` เป็นค่าเข้า
  - reduced motion: keyframe ที่ขยับ (rise, pop, slide, grow) ถูกแทนด้วย fade ภายใน media query เดียวกัน, วนซ้ำเล่นครั้งเดียว,
    แผ่นและ toast เหลือแค่ fade — keyframe ใหม่ที่ขยับต้องเพิ่มเวอร์ชัน fade ไว้ในบล็อกนั้นด้วย
- **การแตะ:** ทุกอย่างที่แตะได้ยุบลงเล็กน้อย (scale ~0.96) ทันทีที่แตะ — แอปต้องตอบภายใน 100ms
- **บอกว่ามาจากไหน ไปไหน:** แผ่นเลื่อนขึ้นจากด้านล่างหรือ "งอก" จากสิ่งที่แตะ · เปลี่ยนเดือนเลื่อนไปทางเดียวกับลูกศร · ตัวเลขยอดนับไปค่าใหม่
  - แตะแถวเพื่อแก้ไข: แผ่นเลื่อนขึ้นเฉยๆ — **ไม่มีของลอยจากแถวเข้าแผ่น (shared element)** ทุกขนาดจอ (เจ้าของสั่งเอาออก 2026-10-24: ไอคอน/ตัวเลขที่บินเข้าดูเด้ง) ·
    modal กลางจอ (คอม) ใช้ fade + scale เท่านั้น
- **ปุ่มใต้ปุ่ม sticky** (เช่น "ลบรายการนี้" ใต้ "บันทึก"): เงาสีพื้นที่ใช้บังของที่เลื่อนผ่านต้องไม่ทับปุ่มนั้น — ปุ่มต้อง `position: relative` + z-index สูงกว่า หรืออยู่ในส่วนล่าง sticky เดียวกัน
- **ของใหม่ต้องหาเจอ:** รายการที่เพิ่งบันทึกมีไฮไลต์มะนาวแล้วจางหายใน ~1.2 วินาที · ลบแล้วแถวยุบตัว แถวล่างเลื่อนขึ้นนุ่มๆ
- **ระหว่างโหลด:** โครงหน้าจอเป็นบล็อกสีทึบจางทรงเดียวกับของจริง (ห้าม shimmer ไล่สี, ไม่ใช้ spinner กลางจอ)
- **ภาพประกอบเคลื่อนไหว (ฉากสาธิตบนหน้าแรก/การตลาด, ระบบ 24):** ทำด้วย HTML/CSS ไม่ใช้วิดีโอ/GIF · เล่นครั้งเดียว (≤ ~3 วินาที) เมื่อเลื่อนถึง
  แล้วค้างเฟรมสุดท้าย + ปุ่ม "ดูอีกครั้ง" — ไม่วนเอง · สไตล์ปกติ = เฟรมสุดท้าย (ก่อนเลื่อนถึง, reduced motion, บอท เห็นฉากที่เสร็จแล้ว) ·
  ฉาก `aria-hidden` ความหมายอยู่ในข้อความใต้ฉาก · การเคลื่อนไหวย่อยใช้ token ปกติ ยกเว้นเส้นสแกนกวาดได้ ~1.2 วินาที
- Splash:
  - พื้นกรมท่า มี wordmark และมะนาว
  - แสดงอย่างน้อย 0.9 วินาที
  - ห้ามกระพริบ
  - ไม่ใช้ภาพ launch ของ iPhone

## UX ที่เจ้าของย้ำ
- เลือกหลายอันก่อน แล้วค่อยกดยืนยันทีเดียว
- ปัดซ้ายเพื่อลบ ต้องมีขั้นยืนยัน
- ข้อความ error เป็นภาษาคน
- ห้ามบอกชื่อผู้ให้บริการอัตราแลกเปลี่ยนใน UI (บอกได้แค่ว่าเป็นอัตราอ้างอิง)
- ถ้ายังไม่ได้เชื่อม AI ให้ซ่อนปุ่มที่เกี่ยวกับ AI
- ภาษาและสกุลเงินเริ่มต้นตั้งตามประเทศของผู้ใช้
- **เลิกทำ (undo):** งานที่ย้อนได้แสดง toast "… · เลิกทำ" ~5 วินาที แทนการถามยืนยัน; งานที่ย้อนไม่ได้ (ลบบัญชี, ล้างข้อมูล) ยังต้องยืนยัน
  — ปัดซ้ายเพื่อลบ: **ถามยืนยันก่อน แล้วมีเลิกทำหลังลบ** (เจ้าของยืนยัน 2026-10-25 — ใช้ทั้งสองอย่าง ไม่ถอดขั้นยืนยัน)
- **หน้าจอเปลี่ยนทันที:** บันทึก/แก้/ลบแสดงผลก่อน แล้วค่อย sync เบื้องหลัง; ล้มเหลว → คืนค่าเดิม + ข้อความภาษาคน
- **ลดการตัดสินใจ:** ค่าเริ่มต้นฉลาด (วันนี้, สกุลเงินหลัก, หมวดที่ใช้บ่อย 4–6 อันขึ้นก่อน); ตัวเลือกขั้นสูงซ่อนไว้ใต้ "เพิ่มเติม" จนกว่าจะใช้
- **ไม่กดดัน ไม่ทำให้รู้สึกผิด:** ไม่มี streak ที่ลงโทษเมื่อขาด; ข้อความเชิงบวก ("วันนี้ยังไม่ได้จด" ไม่ใช่ "คุณพลาด");
  สีเตือน `#d9480f` ใช้เมื่อเกินงบจริงเท่านั้น
- **ตอนจบต้องรู้สึกดี (peak-end):** บันทึกสำเร็จมีมะนาวเด้ง 1 จังหวะ + "จดแล้ว"; ความสำเร็จใหญ่ (เริ่มต้นครบ, อยู่ในงบทั้งเดือน) มีการ์ดฉลองสั้น ข้ามได้ ไม่ปิดกั้น
- **หน้าว่าง:** เป็นงานศิลป์รูปทรงทึบ/มะนาว + ประโยคชวน + ปุ่มเดียวที่ต้องทำ (ห้ามปล่อยหน้าเปล่า)
- **ออฟไลน์:** แถบเล็กสุภาพ "ออฟไลน์ · จะบันทึกเมื่อกลับมาออนไลน์" ไม่ใช่ error
- **Haptic:** สั่นเบาเมื่อบันทึก/ลบ/สลับ (ถ้าเครื่องรองรับ) ปิดได้ใน Settings

## แนะนำการใช้งานครั้งแรก (onboarding)
ตัวอย่างที่ใช้เป็นต้นแบบ: https://claude.ai/artifact/7Zm2vEuuUwgCZLdwgbZDSN (ระบบ 19)
- **สอนตอนจะใช้ ไม่ใช่สไลด์ยาวก่อนใช้** — ห้าม tour หลายหน้าที่ต้องกดถัดไป
- **หน้าต้อนรับหน้าเดียว:** พื้นกรมท่า + รูปทรงทึบ (มะนาว/หยดน้ำ/ใบไม้) ค่อยๆ ลอยขึ้นทีละชิ้น, "สวัสดี มาเริ่มจดกัน", ยืนยันสกุลเงิน + ภาษา (ตั้งตามประเทศแล้ว), ปุ่มเดียว "เริ่มเลย"
- **การ์ด "เริ่มต้นใช้ Daily":** 3 อย่าง (จดรายการแรก · ลองสแกน · ตั้งงบ) ร้อยด้วยแถบมะนาวที่หนาขึ้นเรื่อยๆ ไปถึงมะนาวปลายทาง (ไม่ใช้ตัวเลข);
  แตะแล้วพาไปทำเลย · ทำแล้วจาง + เครื่องหมายถูก · ครบแล้วฉลองครั้งเดียวแล้วการ์ดหาย · ซ่อนได้เสมอ
- **คำใบ้ (coach mark):** ลูกโป่งบล็อกมะนาวทึบชี้ด้วยสามเหลี่ยมทึบ (ไม่มีกรอบ/เงาฟุ้ง), ทีละอัน, ขึ้นครั้งแรกที่เจอจุดนั้น, แตะที่ไหนก็ปิด, ไม่ขึ้นซ้ำ, ไม่ขึ้นทับแผ่นหรือ toast
- ผู้ใช้เก่าไม่เห็นการ์ดเริ่มต้น — เห็นแค่คำใบ้ของฟีเจอร์ใหม่ · ดูอีกครั้งได้จาก Settings
